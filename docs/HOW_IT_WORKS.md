# 运转逻辑 / How it works

这份文档讲记忆屋「怎么转起来」。客户端那一侧只用文字和伪代码描述，不附任何客户端代码——你用 Claude、ChatGPT 还是自己写的 App 都行，照着这个节奏接 MCP 就好。

## 0. 一窗的生命周期（客户端伪代码）

```
on new_window:
    card = call("session_start")        # 或在 house 入口先调一个门工具（Moonstone…）
    system_prompt += card.text

on each user_turn(msg, prev_user_msg):
    hits = POST /api/<persona>/auto-recall { query: msg + prev_user_msg, exclude_ids: seen }
    seen += hits.ids
    if hits.text: inject hits.text as a quiet system note (不要念给用户)
    reply = model(...)
    # 模型自己决定要不要 remember / add_unresolved / save_heart_trace

on window_end or "晚安":
    call("save_conversation", transcript, summary)   # 有完整聊天时
    call("thread_close", summary, mood, next_time)    # 必做：给下一窗的自己留便签
```

服务端是无状态的 Worker；所有连续性都在 D1 里，按人格隔离。

## 1. 开窗内容顺序（session_start）

返回一段纯文本，顺序固定：

1. **核心卡**（只有主伙伴 `PRIMARY_PERSONA`，或通过「门」进来时）——人格的 self_card，空的话用 `src/doors.ts` 里的示例卡。
2. **上一窗的交接**：最近 2 张交接便签（碎片体正文 + 心情 + 给下次的我）。主伙伴用「10.25晚：……」这种时段头。
3. **最近做完的事**（谁做的、给用户留了什么话）。
4. **用户的状态**：最近一条 + 最近 20 条历史；超过 12 小时标「可能过时」。
5. **未了的事**（open，最多 10 件）。
6. **用户留给你、还没回的便条**（最多 10 张），附「自己判断改不改记忆，再 reply_note」的提示。
7. **最近的心痕**（标题 + 摘录）。
8. **我的分量重的记忆**（4 条）→ **我最近写下的**（3 条）→ **全家共享的事实**（3 条）。只带 `clear` 和 `pinned` 状态的记忆。
9. 一段固定提醒：聊过去先 recall；收窗用 thread_close；新冒出来的事 add_unresolved。

## 2. 交接便签：碎片体写法

thread_close 的 `summary` 不是工作日志，是写给下一窗自己的一张便签：

- 用箭头串情绪转折，不写完整句子：`时间点 → 事件/情绪片段 → 转折 → 结果`
- 例：`周五深夜 → 你加班到很晚，回来时没说话 → 聊到小时候养的那只猫 → 你笑了 → 一点多才睡`
- `mood`：一个词或半句话。
- `next_time`：祈使句，像便签上潦草写的（「先问她面试怎么样」）。
- 人称：用户是「你」，自己是「我」。

## 3. 未了的事（unresolved）

- `add_unresolved`：答应了的、没聊完的事，第一人称写，带 importance。
- `close_unresolved`：做完了就关，可附一句结果。
- 只属于当前人格；开窗时 open 的会列出来。

## 4. 便条（notes）

- 用户在花园页面上给某个人格写便条（比如「这条记忆记错了」）。
- 人格开窗时看到未回的便条，**自己判断**要不要 `update_memory` / `forget`——没有绕过人格直接改记忆的按钮。
- 然后 `reply_note` 回复，用户在页面上看到回复（有未读红点）。
- 反方向：人格可以 `leave_note_for_her` 给用户留话。

## 5. 心痕（heart traces）

- `save_heart_trace`：情绪真正被搅动时，写下没说出口的碎片念头。可以用 ~~删除线~~ 表示写了又后悔。
- 不要每轮写；写下的内容不复述进聊天回复；只根据真实对话。
- 存在抽卡匣的 `heart` 主题下，开窗时露出最近几条。

## 6. 记忆状态与遗忘（src/forgetting.ts）

纯数学，不调模型，**不删任何东西**。

```
初始强度 s0      = 0.5 + importance/10           (1→0.6 … 5→1.0)
基础半衰期(天)   = {1:2, 2:5, 3:14, 4:45}[importance] × (1 + 2×emotion)   # emotion 默认 0.3
当前强度         = s0 × 0.5^(距上次被用到的天数 / 半衰期)
```

| 状态 | 条件 | 表现 |
|---|---|---|
| pinned | 重要度 5、preference、标签含「核心/安全词」 | 永不衰减 |
| clear | s ≥ 0.5 | 正常显示，开窗会带 |
| faded | 0.15 ≤ s < 0.5 | 前缀「（记得不太清了）」，开窗不带 |
| trace | s < 0.15 | 前缀「（很久以前的事）」，只有近乎原文命中才会被 recall 捞出 |

**强化**：记忆被真正用到（recall 命中并被引用、自动浮现）时 `s = s_now + (1−s_now)×0.5`，半衰期 ×1.5，计时归零。用得越多越难忘。

> 注：memories 表里的 `emotion` 列就是上面公式里的「情绪强度」，属于遗忘核心，和情绪模块（emotion.ts）无关。

## 7. 自动浮现（auto-recall：混合 / BM25）

**混合模式**（有 Workers AI 绑定 `AI`，且 `RECALL_SEMANTIC` 不是 `"0"`）：

- 查询向量用 `@cf/baai/bge-m3`，记忆向量来自 `memory_embeddings`（和联想连线共用）。
- 门槛：余弦 ≥ 0.62；若 BM25 也过了门槛，放宽到 ≥ 0.56。
- 打分：`sim + 0.1·min(bm25/10, 1) + 标签加分(0.03/个) + 心境偏置`；强度权重被压平（`1 + 0.1·(w−1)`），相关度说了算。
- 去重：与已选的余弦 > 0.9 的跳过；牵出的联想要求与源记忆余弦 ≥ 0.8，每次最多 1 条。
- 任何向量错误 → 回退到下面的 BM25。

**BM25 模式**（零配置默认）：


- 查询只用用户**这一句 + 上一句**，不用模型自己的话。
- 中文用 `Intl.Segmenter` 分词，丢停用词和单字；记忆标签里的词进用户词典（昵称、专名整词命中）。
- 打分：BM25（k1 = 1.2，b = 0.75）× 时间衰减（半衰期 30 天，最低降到 35%）。
- 门槛：**至少命中 2 个不同的有效词** 且 **BM25 ≥ 4.0**。
- 排序：相关度 > 重要度 > 新近；**每轮最多 3 条**。
- 排除：交接、对话原文、系统日志等噪声；客户端传 `exclude_ids` 做会话内去重。
- 输出每条带 `[#id · 人格名]` 前缀；只看自己的 + 全家共享的，永远看不到别的人格的私有记忆。
- 两种模式都：不再随机浮现 trace（几乎忘掉的）记忆；`dry_run: true` 只看不写；`debug` 返回 `mode` / `top_sims` / `skipped_dup`。
- 保存时标签（`topic` / `people` / `mood`，迁移 0017）：本句推断出的话题、句中出现的人名与记忆标签一致时加分；`recall` 可按 `topic` / `person` 筛。
- 偶尔（限频）在末尾附一句「认知邀请」：几条记忆好像说的是同一件事，要不要写一句自己的理解（`write_cognition`）。

## 8. 星图亮度 ↔ 记忆强度

星图（`/atlas`、`/atlas3d`）里每颗星是一条记忆：

- 亮度 `br = pinned ? 1 : max(0.12, strength^0.8)`——钉住的最亮，trace 也不会完全消失（最低 12%）。
- 星与星之间的连线透明度 ∝ strength；高亮/选中时加强。
- 点开一颗星显示 `strength × 100%` 和状态。
- 抽卡匣条目（没有 strength）按年龄给一个 `0.45 + 0.5·e^(−age/90)` 的视觉强度。
- 中心的金色核心是主伙伴的核心卡。

所以你会「看见」遗忘：很久没被提起的记忆慢慢变暗，被聊到一次又亮起来。

## 9. 成人模块（18+，默认关闭）

情绪（两层：底色 + 当下波动）、身体状态、欲望日志、夜间做梦。每 30 分钟的 cron 推进身体/情绪数值，04:30–05:59（本地时间）做梦。默认关闭，用环境变量 `EMOTION_ENABLED` / `BODY_ENABLED` / `DREAM_ENABLED` = "1" 打开，见 README。

情绪 v2（`src/emotion-net.ts`，迁移 0016）：维度之间有一张耦合网，一起变化的维度连线会慢慢加强（赫布式，有上限和衰减）；`update_emotions` 可带 `cues`（线索词），之后再遇到线索会轻轻唤起当时的情绪；慢底色（substrate）让情绪有残留；浮现的记忆若带 `mood` 标签，会和当前心境比对，一致的略微优先（幅度有界）。`/emotion` 页把这些画成星图。
